Rename the CLI entry point la → linear-a, and guard the optional engine import

la was too collision-prone for a global name; linear-a is unambiguous. The
package __init__ eagerly imported the engine's session module, which the
linear-a engine does not ship, breaking every import though the CLI never
uses it — now re-exported only when the engine provides it, and the dead
sys.path shim dropped since the engine installs as a package.
